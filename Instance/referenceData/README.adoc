== Introduction

This README complements the machine-readable link:https://github.com/entsoe/relicapgrid/blob/cgmes-3.0_ncp-2.4_tc-1.1/Instance/referenceData/Grid/manifest.ttl[manifest] and provides a human-readable description of the **ReliCapGrid Reference Data** within the *ReliCapGrid* repository.

The reference data contains controlled vocabulary and reference scheme datasets used for standardized classification and metadata across all ReliCapGrid models.

Reference datasets publish the recognized identities for confidentiality levels, licenses, activities, parties, test frames, model versions, and conformance releases.
These are used throughout the repository to ensure consistent, machine-readable metadata in manifests and dataset descriptions.

The datasets are compliant with the *ENTSO-E Network Code data exchange specifications* (profiles).
The datasets are validated with SHACL constraints available in link:https://github.com/entsoe/application-profiles-library[ENTSO-E Application Profiles Library] repository and are subject to review by the ENTSO-E Standard Vetting Interoperability Tests (SV-IOP).

== Model Scope and Content

The reference data includes datasets organised into the following folders:

* *Grid* – Reference schemes for dataset metadata:
** ConfidentialityScheme – Recognized confidentiality and access-right classifications
** LicenseScheme – Recognized license concepts (open, non-commercial, restricted derivation)

* *NetworkCode* – Reference schemes for Network Code data exchange:
** ActivityScheme – Recognized activity identities for provenance references
** ConformanceReleaseScheme – Conformance release levels for NCP 2.4
** FrameScheme – Recognized frame identities for area-of-responsibility references
** ModelScheme – Recognized abstract model identities for dataset versioning and cataloguing
** PartyScheme – Recognized party identities for publisher, authority, and provenance references

* *ChangeSet* – Planned for future development; will contain incremental updates to reference scheme definitions.

== Purpose and Intended Use

The ReliCapGrid reference data is intended for:

* Providing the shared controlled vocabularies required for consistent metadata across all ReliCapGrid datasets
* Interoperability and conformance testing of reference data exchange
* Toolchain validation (metadata handling, conformance level checking)
* Training, documentation, and demonstration purposes

== Package Structure and Serializations

The package is provided in multiple serializations:

* `cimxml/` – According to *IEC 61970-552:2016* which is the main serialization used for *IEC 61970-600-1* (CGMES) datasets and for ENTSO-E Network Code profiles.

* `jsonld/` –
  CIM JSON-LD representations aligned with *IEC 61970-553* (under development), enabling integration with semantic and data-driven tooling.
  This serialization is not currently provided and may be added in the future. (CIM JSON-LD is generated from CIMXML.)

* `trig/` – link:https://www.w3.org/TR/trig/[TriG] representation for improved readability and semantic inspection. (TriG is generated from CIMXML.)

CIMXML SHALL be treated as the primary data exchange serialization for this package unless otherwise explicitly stated.
